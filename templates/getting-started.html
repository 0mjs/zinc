Installation

Getting started with Zinc is easy. Make sure you have Go 1.24 or later installed, then add Zinc to your project:

Terminal
go get -u github.com/0mjs/zinc

Basic Example

Here's a simple example to get you started with Zinc:

main.go
package main

import "github.com/0mjs/zinc"

func main() {
    // Create a new Zinc app
    app := zinc.New()
    
    // Define a simple route
    app.Get("/", func(c *zinc.Context) {
        c.Send("Hello from Zinc!")
    })
    
    // JSON response example
    app.Get("/api/data", func(c *zinc.Context) {
        c.JSON(zinc.Map{
            "name": "Zinc",
            "language": "Go",
            "version": "1.0.0",
        })
    })
    
    // Start the server
    app.Serve(":3000")
}

Run your application:

Terminal
go run main.go

Your server will be available at http://localhost:3000.

Routing

Zinc provides a powerful and flexible routing system that makes it easy to define HTTP endpoints:

routing.go
// Basic route
app.Get("/hello", func(c *zinc.Context) {
    c.Send("Hello World!")
})

// Route with path parameters
app.Get("/users/:id", func(c *zinc.Context) {
    id := c.Param("id")
    c.JSON(zinc.Map{"user_id": id})
})

// Route with multiple parameters
app.Get("/posts/:category/:id", func(c *zinc.Context) {
    category := c.Param("category")
    id := c.Param("id")
    c.JSON(zinc.Map{
        "category": category,
        "post_id": id,
    })
})

// Wildcard route
app.Get("/files/*filepath", func(c *zinc.Context) {
    filepath := c.Param("*")
    c.Send("You requested: " + filepath)
})

// HTTP methods
app.Post("/users", createUser)
app.Put("/users/:id", updateUser)
app.Delete("/users/:id", deleteUser)
app.Patch("/users/:id", partialUpdateUser)
app.Head("/health", healthCheck)
app.Options("/cors-enabled", handleOptions)

Route Groups

Organize routes with common prefixes and middleware using route groups:

groups.go
// Create an API group
api := app.Group("/api")

// Routes in this group will have /api prefix
api.Get("/users", listUsers)
api.Post("/users", createUser)

// Nested groups
v1 := api.Group("/v1")
v1.Get("/products", listProductsV1)

// Group with middleware
admin := app.Group("/admin")
admin.Use(requireAuth)
admin.Get("/dashboard", showDashboard)
admin.Get("/users", listAllUsers)

Middleware

Middleware provides a way to execute code before or after request handlers. You can use middleware for cross-cutting concerns like logging, authentication, error handling, and more.

middleware.go
// Global middleware (applies to all routes)
app.Use(func(c *zinc.Context) {
    start := time.Now()
    c.Set("requestId", uuid.New().String())
    
    // Call the next middleware or handler
    c.Next()
    
    // Code here executes after the request handler
    duration := time.Since(start)
    fmt.Printf("Request processed in %v\n", duration)
})

// Logger middleware
func Logger(c *zinc.Context) {
    start := time.Now()
    path := c.Request.URL.Path
    
    c.Next()
    
    latency := time.Since(start)
    fmt.Printf("[%s] %s %s - %v\n", 
        c.Method, path, c.Request.RemoteAddr, latency)
}

// Authentication middleware
func RequireAuth(c *zinc.Context) {
    token := c.Request.Header.Get("Authorization")
    if token == "" {
        c.Status(401).JSON(zinc.Map{
            "error": "Unauthorized: missing token",
        })
        return // don't call Next()
    }
    
    // For a valid token, continue to the next handler
    c.Next()
}

// Apply middleware to specific routes
app.Get("/public", publicHandler)
app.Get("/private", RequireAuth, privateHandler)

// Middleware on route groups
api := app.Group("/api")
api.Use(Logger)
api.Get("/data", getData)

The Context

The Context object is passed to all handlers and middleware. It provides access to the request and response, as well as utilities for working with requests and sending responses.

context.go
// Access request information
app.Get("/example", func(c *zinc.Context) {
    // Get path parameters
    id := c.Param("id")
    
    // Get query parameters
    sort := c.Query("sort")
    page := c.Query("page")
    
    // Check if query parameter exists
    if c.HasQuery("filter") {
        filter := c.Query("filter")
        // Use filter
    }
    
    // Access raw request
    r := c.Request
    method := r.Method
    url := r.URL.String()
    headers := r.Header
    cookies := r.Cookies()
    
    // Parse request body into struct
    var user User
    if err := c.Body(&user); err != nil {
        c.Status(400).JSON(zinc.Map{"error": "Invalid request body"})
        return
    }
    
    // Store data in context for middleware
    c.Set("user", user)
    
    // Access stored data
    if value, ok := c.Get("requestId").(string); ok {
        // Use value
    }
    
    c.Send("Request processed")
})

// Access services
app.Service("db", database)
app.Service("cache", redisClient)

app.Get("/data", func(c *zinc.Context) {
    db := c.Service("db").(*Database)
    data := db.Query("SELECT * FROM items")
    c.JSON(data)
})

Sending Responses

Zinc provides several methods for sending different types of responses:

responses.go
// String response
app.Get("/text", func(c *zinc.Context) {
    c.Send("Hello World!")
})

// JSON response
app.Get("/json", func(c *zinc.Context) {
    c.JSON(zinc.Map{
        "message": "Success",
        "data": []string{"item1", "item2", "item3"},
    })
})

// HTML response
app.Get("/html", func(c *zinc.Context) {
    c.HTML("
Hello Zinc!
Welcome to our website
")
})

// Serve static files
app.Get("/file", func(c *zinc.Context) {
    c.Static("path/to/file.pdf")
})

// Set status code
app.Get("/not-found", func(c *zinc.Context) {
    c.Status(404).Send("Not Found")
})

// Send binary data
app.Get("/binary", func(c *zinc.Context) {
    data := []byte{0x00, 0x01, 0x02, 0x03}
    c.Send(data)
})
