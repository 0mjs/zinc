What is Zinc?

Zinc is a high-performance, minimalist web framework for Go designed to build robust APIs with ease. Created as an alternative to frameworks like Gin, Echo, Chi, and Fiber, Zinc focuses on providing the perfect balance between performance, simplicity, and features.

Built for modern Go applications (Go 1.24+), Zinc leverages the power of Go's standard library while adding convenient abstractions to simplify common web development tasks without sacrificing performance.

main.go
package main

import "github.com/0mjs/zinc"

func main() {
    app := zinc.New()
    
    app.Get("/", func(c *zinc.Context) {
        c.Send("Hello World!")
    })
    
    app.Get("/json", func(c *zinc.Context) {
        c.JSON(zinc.Map{
            "message": "Welcome to Zinc",
            "version": "1.0.0",
        })
    })
    
    app.Serve(":3000")
}

Key Features

High Performance

Optimized routing with route caching and minimized allocations for efficient request handling.

Elegant API

Clean, intuitive API that makes building web services straightforward and enjoyable.

Advanced Routing

Fast router with support for static routes, path parameters, wildcards, and route groups.

Middleware Support

Flexible middleware system for cross-cutting concerns like logging, authentication, and more.

WebSocket Support

Built-in WebSocket handling with room management for real-time applications.

Cron Jobs

Integrated scheduler for background tasks and periodic jobs.

Validation

Request validation utilities to ensure data integrity.

Service Container

Dependency injection to manage and access your application's services.

Performance

Zinc is built with performance as a primary goal. The framework employs several optimization techniques:

  • Route caching for faster lookups
  • Pooled objects to reduce GC pressure
  • Zero-allocation path handling where possible
  • Fast static route resolution path
  • Optimized header handling

Benchmark results show Zinc's performance is competitive with or exceeds other popular Go frameworks.

Philosophy

Zinc follows these core principles:

  • Simplicity: Provide a clean, intuitive API without unnecessary abstractions
  • Performance: Optimize for speed without sacrificing usability
  • Pragmatism: Include features that solve real-world problems
  • Standard library friendly: Work well with Go's standard library
  • Minimal dependencies: Rely on as few external packages as possible

Comparison with Other Frameworks

While there are several excellent Go web frameworks available, Zinc sets itself apart by focusing on a balance of features, performance, and developer experience.

  • vs. Gin: Similar API with better performance characteristics and lower memory usage
  • vs. Echo: Comparable feature set with a more streamlined API
  • vs. Chi: More built-in features while maintaining excellent performance
  • vs. Fiber: Comparable performance without the dependency on a non-standard HTTP implementation
