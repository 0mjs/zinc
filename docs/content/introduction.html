Introduction

Zinc is a lightweight, high-performance web framework for Go focused on simplicity and speed.

Installation

1 Install Zinc using Go modules 
go get github.com/0mjs/zinc

Zinc requires Go 1.22 or later for optimal performance.

Hello World Example

1 Create a new file named main.go 
package main

import (
	"net/http"

	"github.com/0mjs/zinc"
)

func main() {
	app := zinc.New()

	app.Get("/", func(c *zinc.Context) error {
		return c.String(http.StatusOK, "Hello, Zinc!")
	})

	app.Start(":8080")
}
2 Run your application 
go run main.go
3 Visit http://localhost:8080 in your browser

You should see "Hello, Zinc!" displayed in your browser.

That's it! You've successfully created your first Zinc application. For more details, check out the Guide or explore Core Concepts.
