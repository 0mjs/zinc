<section class="z-manifesto">
  <div class="z-section-intro">
    <span>WHAT ZINC ADDS</span>
    <h2>Application code without the ceremony.</h2>
    <p>Zinc fills the practical gaps above the standard library. Nothing underneath is replaced.</p>
  </div>

  <div class="z-principles">
    <article>
      <b>01</b>
      <div><h3>Write the common path quickly.</h3><p>Concise routes, groups, binding, response helpers, and one central place for errors.</p></div>
      <code>{'app.Get("/users/{id}", showUser)'}</code>
    </article>
    <article>
      <b>02</b>
      <div><h3>Keep standard Go within reach.</h3><p>A Zinc app is an <code>http.Handler</code>. The original request and response writer stay available.</p></div>
      <code>server.Handler = app</code>
    </article>
    <article>
      <b>03</b>
      <div><h3>Bring the ecosystem with you.</h3><p>Mount existing handlers and wrap the application with ordinary HTTP middleware.</p></div>
      <code>app.HandleHTTP(pattern, handler)</code>
    </article>
  </div>
</section>

<section class="z-native">
  <div class="z-section-intro">
    <span>NATIVE BY DESIGN</span>
    <h2>Mix framework and standard handlers.</h2>
    <p>Choose the shortest API for your own code. Keep third-party and standard-library integrations standard.</p>
  </div>

  <div class="z-native-code">
    <div>
      <span>ZINC HANDLER</span>
      <Code code={`app.Get("/users/{id}", func(c *zinc.Context) error {
    return c.String(c.Param("id"))
})`} lang="go" theme="tokyo-night" />
    </div>
    <i>+</i>
    <div>
      <span>STANDARD HANDLER</span>
      <Code code={`app.HandleHTTP(
    "GET /metrics",
    promhttp.Handler(),
)`} lang="go" theme="tokyo-night" />
    </div>
    <i>=</i>
    <div class="result">
      <span>ONE APPLICATION</span>
      <Code code={`server := &http.Server{
    Addr:    ":8080",
    Handler: app,
}
log.Fatal(server.ListenAndServe())`} lang="go" theme="tokyo-night" />
    </div>
  </div>
</section>
